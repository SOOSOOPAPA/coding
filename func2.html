🧩 함수 설계 활동 ② — 지역 변수 · 전역 변수 · 함수 2개

함수 안에서 만든 지역 변수와 함수 밖의 전역 변수를 사용해 보고, 마지막 문제 6에서는 계산하는 함수와 출력하는 함수 2개를 연결해 보자.

지역 변수전역 변수global매개 변수 없는 함수몫 연산 //함수 2개매개 변수 2개map·split

💡 핵심 개념 — 지역 변수 · 전역 변수 · 함수 2개 연결

지역 변수 — 함수 안에서 만든 변수
def calc(a):
    s = a * 2      # s는 지역 변수
    return s

print(calc(5))     # 10
print(s)           # 오류! 함수 밖에서는 s가 없음
전역 변수 — 함수 밖에서 만든 변수
cnt = 0          # 전역 변수

def add():
    global cnt   # 값을 '바꿀' 때는 global 필요
    cnt = cnt + 1

def show():
    return cnt   # '읽기만' 할 때는 필요 없음

add()
add()
print(show())    # 2
함수 2개 연결 · 한 줄에 두 값 입력
def area(w, h):        # 매개 변수 2개
    return w * h

def show(a):           # 결과를 받아 출력
    print(str(a) + "칸")

w, h = map(int, input().split())
show(area(w, h))       # 안쪽 area()가 먼저 실행
# 입력 3 4  →  출력 12칸
  • 지역 변수는 그 함수가 실행되는 동안에만 있고, 함수 밖에서는 쓸 수 없습니다. 매개 변수도 지역 변수입니다.
  • 함수 안에서 전역 변수의 값을 바꾸려면 global 변수이름을 먼저 써야 합니다. 없으면 UnboundLocalError가 납니다. 읽기만 할 때는 필요 없습니다.
  • //는 나눗셈의 몫을 구하는 연산자입니다. (7 // 2 → 3)
  • show(area(w, h))처럼 쓰면 안쪽 함수의 반환값이 바깥 함수의 매개 변수로 들어갑니다.
  • map(int, input().split())은 3 4처럼 공백으로 구분한 두 값을 정수로 바꿔 한 번에 입력받고, str(12) + "칸"처럼 숫자와 글자를 붙여 쓸 수 있습니다.

문제 4 3의 배수 개수 세기 함수

지역 변수for 반복문if 조건문반환값교과서 140~142쪽

정수 n을 전달받아, 1부터 n까지의 수 중 3의 배수가 몇 개인지 세어 반환하는 함수 count3()을 설계해 보자.

조건

  • 함수 이름은 count3, 매개 변수는 1개로 합니다.
  • 개수를 세는 변수는 함수 안에서 만들어 사용합니다. (지역 변수)
  • 키보드로 정수 한 개를 입력받아 함수에 전달하고, 반환된 개수를 출력합니다.

입출력 예시

번호입력출력설명
11033, 6, 9
22063, 6, 9, 12, 15, 18
3203의 배수가 없음
💡 힌트
  • 1부터 n까지 반복하려면 range(1, n+1)을 사용합니다. (n까지 포함하려면 n+1)
  • 3의 배수인지는 i % 3 == 0으로 확인합니다.
  • 개수를 세는 변수는 반복문 전에 0으로 정해 두고, 조건이 맞을 때마다 1씩 더합니다.
  • return은 반복문이 모두 끝난 뒤에 실행되도록 들여쓰기 위치에 주의합니다.

문제 5 용돈 저금통

함수 2개전역 변수global매개 변수 없는 함수몫 연산 //교과서 142~144쪽

용돈을 받을 때마다 절반을 저금하려고 한다. 저금한 금액을 전역 변수 total에 모으는 함수와, 목표 금액(3000원)을 달성했는지 알려 주는 함수를 만들어 보자.

함수 설계도

함수하는 일매개 변수반환값
save(money)받은 용돈의 절반(money // 2)을 전역 변수 total에 더함받은 용돈없음
check()total이 3000 이상이면 목표 달성!
그 외 조금 더 모으자		없음결과 문장

조건

  • 프로그램 맨 위에 전역 변수 total = 0을 만듭니다.
  • save()는 출력도 반환도 하지 않고, 전역 변수 total의 값을 바꿉니다.
  • check()는 매개 변수 없이 결과 문장을 return합니다.
  • 용돈을 한 줄에 하나씩 3번 입력받은 뒤, 저금한 금액과 결과를 출력합니다.

결과: 목표 달성!		1000+1500+500 = 3000

결과: 조금 더 모으자		500+1000+250 = 1750

결과: 목표 달성!		2001 // 2 = 1000 (몫만 남음)
💡 힌트
  • 함수 안에서 전역 변수의 값을 바꾸려면 함수 첫 줄에 global total을 씁니다.
  • //는 나눗셈의 몫만 구합니다. (2001 // 2 → 1000) /를 쓰면 1000.5처럼 소수가 나옵니다.
  • 매개 변수가 없는 함수는 def check():처럼 괄호를 비워 두고, 호출할 때도 check()라고 씁니다.
  • check()는 total을 읽기만 하므로 global을 쓰지 않아도 됩니다.

문제 6 게임 시간 체크

함수 2개매개 변수 2개return과 출력지역 변수한 줄에 두 값 입력교과서 131쪽 · 135~144쪽
📖 이야기
준호는 엄마와 하루 게임 시간을 지키기로 약속했다. 3일 동안 게임한 시간을 시간과 분으로 입력하면, 분으로 바꾸어 약속을 잘 지켰는지 알려 주는 프로그램을 만들어 주자. (60분 이하 적당해요, 120분 이하 조금 많아요, 그 외 너무 많아요)

시간과 분을 전체 분으로 바꾸어 반환하는 함수와, 분을 받아 결과를 출력하는 함수, 두 개의 함수를 만들어 보자.

함수 설계도

함수하는 일매개 변수반환값
to_min(h, m)시간과 분을 전체 분으로 바꿈시간, 분전체 분
judge(t)결과를 지역 변수 msg에 저장한 뒤 출력분없음 (함수 안에서 출력)

조건

  • to_min()은 매개 변수 2개를 받아 전체 분을 return합니다.
  • judge()는 결과를 함수 안의 지역 변수 msg에 저장한 뒤, 90분 -> 조금 많아요 형식으로 함수 안에서 출력합니다.
  • to_min()의 반환값을 judge()에 전달합니다.
  • 게임 시간은 1 30처럼 시간과 분을 공백으로 구분해 한 줄에 입력합니다.
  • 하루치를 입력할 때마다 바로 한 줄씩 결과를 출력하며, 이것을 3일분 반복합니다.

💡 힌트
  • 한 줄에 두 값을 입력받으려면 h, m = map(int, input().split())을 사용합니다.
  • to_min(h, m)처럼 매개 변수가 2개이면, 호출할 때도 값을 순서대로 2개 넣습니다.
  • judge() 안에서 if - elif - else로 msg에 문장을 저장하고, 마지막에 한 번만 출력합니다.
  • judge(to_min(h, m))처럼 쓰면 안쪽 to_min()이 먼저 실행되고, 그 결과가 judge()로 전달됩니다.
  • str(t) + "분 ->"처럼 쓰면 숫자와 글자를 붙여 90분 ->으로 출력할 수 있습니다.
