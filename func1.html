🧩 함수 설계 활동 ① — return과 print

매개 변수로 값을 전달받아 조건에 따라 결과를 반환하는 함수와, 함수 안에서 직접 출력하는 함수를 비교하며 설계해 보자.

def매개 변수return 반환값함수 안에서 출력if·elseif·elif·else

💡 핵심 개념 — 함수의 결과를 전달하는 두 가지 방법

① 함수 안에서 출력하기
def hello(name):
    print("안녕,", name)   # 함수가 직접 출력

hello("민수")              # 호출만 하면 됨
# 실행 결과: 안녕, 민수
② return으로 돌려주기
def double(n):
    return n * 2          # 값을 돌려줌

print(double(5))          # 밖에서 출력해야 보임
# 실행 결과: 10
  • 함수 안에서 출력한 함수는 호출만 합니다. print(hello("민수"))처럼 감싸면 마지막에 None이 더 출력됩니다.
  • return으로 돌려준 함수는 밖에서 print()로 감싸야 화면에 보입니다. 호출만 하면 아무것도 나오지 않습니다.
  • 문제의 조건에서 어느 방법을 쓰라고 했는지 꼭 확인하세요.

문제 1 홀수·짝수 알려 주는 함수

매개 변수반환값if-else교과서 135~139쪽

정수 한 개를 전달받아, 그 수가 짝수이면 "짝수", 홀수이면 "홀수"를 반환하는 함수 f()를 설계해 보자.

조건

  • 함수 이름은 f, 매개 변수는 1개로 합니다.
  • 함수 안에서 print()로 출력하지 말고, 결과를 return으로 돌려줍니다.
  • 키보드로 정수 한 개를 입력받아 함수에 전달하고, 반환된 값을 출력합니다.

입출력 예시

번호입력출력설명
17홀수7 ÷ 2의 나머지는 1
210짝수10 ÷ 2의 나머지는 0
30짝수0도 짝수
💡 힌트
  • 2로 나눈 나머지는 % 연산자로 구합니다. (7 % 2 → 1)
  • 나머지가 0이면 짝수, 아니면 홀수이므로 if - else를 사용합니다.
  • 반환값을 출력하려면 print(f(n))처럼 함수 호출을 print() 안에 넣습니다.

문제 2 시험 통과 알림 함수

매개 변수 1개함수 안에서 출력반환값 없음if-else교과서 135~139쪽

점수를 전달받아 60점 이상이면 통과입니다, 그렇지 않으면 재시험입니다를 함수 안에서 직접 출력하는 함수 check()를 설계해 보자.

조건

  • 함수 이름은 check, 매개 변수는 1개로 합니다.
  • 함수 안에서 print()로 출력합니다. return은 사용하지 않습니다.
  • 점수를 입력받아 함수를 호출만 합니다. (print()로 감싸지 않음)

입출력 예시

번호입력출력설명
175통과입니다
260통과입니다60점도 통과
345재시험입니다
💡 힌트
  • 문제 1과 달리 이번에는 함수 안에서 print("통과입니다")처럼 바로 출력합니다.
  • 60점도 통과이므로 조건은 score >= 60입니다.
  • 함수가 직접 출력하므로, 함수 밖에서는 check(score)라고 호출만 하면 됩니다.

문제 3 성적 등급 함수

매개 변수반환값if-elif-else교과서 139쪽 응용

점수를 전달받아 등급을 반환하는 함수 grade()를 설계해 보자. 등급 기준은 아래 표와 같습니다.

조건

  • 90점 이상 → A, 80점 이상 → B, 70점 이상 → C, 70점 미만 → D
  • 함수 이름은 grade, 매개 변수는 1개로 합니다.
  • 점수는 0 이상 100 이하의 정수로 입력합니다.

입출력 예시

번호입력출력설명
185B80점 이상 90점 미만
290A90점도 A
362D70점 미만
💡 힌트
  • 조건이 4가지로 나뉘므로 if - elif - else를 사용합니다.
  • 높은 점수 조건부터 차례대로 검사하면 범위를 따로 쓰지 않아도 됩니다. (s >= 90 → s >= 80 → …)
  • return이 실행되면 함수는 바로 끝나므로 나머지 조건은 검사하지 않습니다.
